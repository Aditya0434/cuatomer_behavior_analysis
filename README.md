# Customer Shopping Behavior Analysis

## 📌 Overview

This project analyzes **customer shopping behavior** using transactional data from **3,900 purchases** across different product categories.

The objective is to explore customer spending patterns, identify customer segments, understand product preferences, and analyze subscription and discount behavior to generate actionable business insights.

The project follows a complete **Data Analytics workflow**:

**Python → Data Cleaning & EDA → SQL Analysis → Power BI Dashboard → Business Report → Presentation**

---

## 📊 Dataset

The dataset contains **3,900 rows and 18 columns**.

### Key Features

* Customer demographics

  * Age
  * Gender
  * Location
  * Subscription Status
* Purchase information

  * Item Purchased
  * Category
  * Purchase Amount
  * Season
  * Size
  * Color
* Shopping behavior

  * Discount Applied
  * Previous Purchases
  * Frequency of Purchases
  * Review Rating
  * Shipping Type

### Data Quality

The dataset contained **37 missing values in the Review Rating column**. These were handled during the data-cleaning stage using the median rating of each product category.

## 🔄 Project Workflow

### 1. Data Loading

The dataset was imported into Python using **Pandas**.

Initial exploration was performed using:

* `df.info()`
* `df.describe()`
* Null-value checks
* Basic data inspection

This helped understand the structure, data types, and statistical characteristics of the dataset.

---

### 2. Data Cleaning

The following data-cleaning steps were performed:

* Checked for missing values
* Imputed missing `review_rating` values using category-level median ratings
* Standardized column names using **snake_case**
* Checked for redundant columns
* Removed `promo_code_used` after comparing it with `discount_applied`

These steps improved data consistency and prepared the dataset for further analysis.

---

### 3. Exploratory Data Analysis

EDA was performed in Python to understand customer and purchasing patterns.

Key activities included:

* Descriptive statistics
* Customer demographic analysis
* Purchase behavior analysis
* Product and category analysis
* Subscription analysis
* Discount behavior analysis
* Customer segmentation

### Feature Engineering

Two additional features were created:

* `age_group` — customer age categories
* `purchase_frequency_days` — purchase frequency converted into days

---

### 4. SQL Analysis

The cleaned dataset was loaded into **PostgreSQL** for structured business analysis.

SQL queries were used to answer important business questions such as:

1. Revenue generated by gender
2. High-spending customers using discounts
3. Top 5 products based on average rating
4. Average purchase amount by shipping type
5. Subscribers vs. non-subscribers
6. Products with the highest percentage of discounted purchases
7. Customer segmentation into New, Returning, and Loyal
8. Top 3 products within each category
9. Relationship between repeat purchases and subscriptions
10. Revenue contribution by age group

The project report summarizes the analysis and converts the findings into business-oriented recommendations.

### Key Recommendations

* **Increase subscriptions** by offering exclusive benefits to subscribers.

* **Review discount strategies** to balance increased sales with profit margins.
* **Promote top-rated and best-selling products** through targeted campaigns.
* **Use targeted marketing** for high-revenue customer age groups and express-shipping users.
